# 融资租赁智能推荐系统 (最终版)

## 1. 项目目标 (Project Goal)

本项目旨在构建一个基于PageRank算法的智能推荐系统。它通过分析融资租赁市场中各参与方（承租人、出租人）及其属性（地区、行业、交易规模、期限）之间的复杂关系，为特定的承租人画像（例如“山东省的农林牧渔行业客户”）智能推荐最匹配、最重要的出租人。

最终交付的是一个独立的Python脚本，它封装了从数据处理到最终推荐的完整流程。

## 5. 模型工作原理 (How the Model Works)

我们最终采用的方案是一个统一的、信息更丰富的**异构图模型 (Heterogeneous Graph)**。

### 5.1 图谱结构 (Graph Structure)

我们构建的是一个包含**6种不同类型节点**的图：
1.  **省份 (Province)**
2.  **行业 (Industry)**
3.  **价值分箱 (Value Bin)**
4.  **期限分箱 (Term Bin)**
5.  **承租人 (Lessee)**
6.  **出租人 (Lessor)**

这些节点通过三种核心的、**带权重**的边连接起来，形成一个复杂的网络。

### 5.2 边的权重计算 (Edge Weight Calculation)

#### **连接类型 1：属性 -> 承租人**
*   **描述**: 将一个“属性节点”（如“山东省”）与一个在该属性下有业务的“承租人节点”连接。
*   **权重计算**: 这个权重衡量的是**该承租人在该属性下的重要性占比**。
*   **公式**: `权重 = (承租人A在山东省的交易次数) / (山东省发生的所有交易的总次数)`
*   **意义**: 衡量承租人在特定领域内的“关键参与者”地位。

#### **连接类型 2：承租人 -> 出租人**
*   **描述**: 将一个“承租人节点”与和它有过合作的“出租人节点”连接。
*   **权重计算**: 这个权重衡量的是**双方合作的紧密程度**。
*   **公式**: `权重 = (承租人A与出租人B之间的总交易次数)`

#### **连接类型 3：省份 <-> 省份**
*   **描述**: 为了解决数据稀疏问题，我们在业务模式相似的省份之间建立连接。
*   **相似度计算**: 我们首先通过分析各省份的“行业分布”，使用K-Means算法将省份聚类成几个大组。然后计算同组内各省份之间的“余弦相似度”。
*   **权重计算**: 这条双向边的权重就是它们两者之间的**余弦相似度得分**。
*   **意义**: 这允许PageRank的“能量”在相似的省份之间流动，让数据稀疏的省份可以“借鉴”其相似省份的关系网络来获得更丰富的推荐。

### 5.3 推荐流程 (Recommendation Process)

1.  **确定起点**: 脚本中定义的查询条件（省份、行业、价值分箱、期限分箱）对应的四个属性节点，成为PageRank算法的“能量”注入点。
2.  **个性化设置**: 我们创建一个“个性化向量”，将100%的初始能量平均分配给这四个起点节点。
3.  **能量流动**: PageRank算法开始模拟“随机游走”。能量从起点出发，沿着带权重的边流动，经过省份、行业、承租人，最终汇集到出租人节点。
4.  **最终评分**: 每个“出租人节点”最终积累的“能量值”，就是它的最终PageRank评分。这个分值综合反映了它与您查询的四个属性维度的关联紧密程度。
5.  **输出排名**: 脚本最后将所有出租人按此综合评分从高到低排序，并展示前十名。
